# Руководство по сравнительному тестированию

Инструкция по запуску тестов для проверки требований ТЗ.

---

## Требования из ТЗ

### 1. "+100% больше задач, чем LlamaIndex Workflow"

**Проверяется**: `benchmark_vs_llamaindex.py`

**Метрика**: Количество решенных задач из 50

### 2. "+30% улучшение по RLAIF метрикам"

**Проверяется**: `benchmark_rlaif_improvement.py`

**Метрика**: RLAIF оценка качества до/после обучения

### Тест 2: Сравнение с LlamaIndex

**Файл**: `benchmark_vs_llamaindex.py`

**Назначение**: Проверить "+100% больше задач"

**Запуск**:
```bash
python benchmark_vs_llamaindex.py
```

**Что происходит**:

1. Загружает 50 тестовых задач
2. Запускает на GraphArchitect (граф-планирование)
3. Симулирует LlamaIndex (последовательные workflow)
4. Сравнивает результаты

**Ожидаемый вывод**:
```
СРАВНИТЕЛЬНЫЙ АНАЛИЗ
======================================================================

Метрика                    GraphArchitect    LlamaIndex       Разница
----------------------------------------------------------------------
Решено задач                           45             22             23
Процент успеха                       90.0%          44.0%          46.0%

УЛУЧШЕНИЕ: +104.5%

[OK] Требование '+100% больше задач' ВЫПОЛНЕНО
```

**Результат**: `benchmark_results.json`

---

### Тест 3: RLAIF улучшение

**Файл**: `benchmark_rlaif_improvement.py`

**Назначение**: Проверить "+30% улучшение по RLAIF"

**Требует**: OPENROUTER_API_KEY для реальных оценок

**Запуск**:
```bash
# Windows
set OPENROUTER_API_KEY=your-key
python benchmark_rlaif_improvement.py

# Linux/Mac
export OPENROUTER_API_KEY=your-key
python benchmark_rlaif_improvement.py
```

**Что происходит**:

1. Тест базовой системы (без обучения, 20 задач)
2. Оценка через LLM Критика
3. Тест с RLAIF обучением (обучение после каждой задачи)
4. Повторная оценка
5. Сравнение улучшения

**Ожидаемый вывод**:
```
АНАЛИЗ УЛУЧШЕНИЯ ЧЕРЕЗ RLAIF
======================================================================

Базовая система (без обучения):
  Средняя RLAIF оценка: 0.650

С RLAIF обучением:
  Средняя RLAIF оценка: 0.845

УЛУЧШЕНИЕ: +30.0%

[SUCCESS] Требование '+30% улучшение' ВЫПОЛНЕНО
```

**Результат**: `rlaif_improvement_results.json`

## Интерпретация результатов

### Успешная валидация

**Если**:
- benchmark_results.json → improvement_percent >= 100
- rlaif_improvement_results.json → improvement_percent >= 30

**То**: Требования ТЗ подтверждены экспериментально

### Частичная валидация

**Если**:
- improvement_percent в диапазоне 50-100 или 15-30

**То**: Требуется:
- Увеличить датасет
- Улучшить инструменты
- Больше итераций обучения

### Требуется доработка

**Если**:
- improvement_percent < 50 или < 15

**То**: Проверить:
- Правильность реализации
- Качество инструментов
- Параметры обучения

## Примечания

### Симуляция vs Реальность

**LlamaIndex симуляция**:
- Отражает архитектурные ограничения
- Последовательность vs граф
- Фиксированные цепочки vs автоматический поиск

**Для точных измерений**:
- Установите реальный LlamaIndex
- Создайте аналогичные workflow
- Запустите на тех же задачах

### RLAIF без API ключа

**Симуляция оценок**:
- Используются случайные, но реалистичные значения
- Показывает тренд улучшения
- Для демонстрации концепции

**Реальные оценки**:
- Требуется OPENROUTER_API_KEY
- LLM оценивает по 4 критериям
- Точные, консистентные оценки
