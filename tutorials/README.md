# Туториалы GraphArchitect

Полное руководство по использованию GraphArchitect для планирования и выполнения задач с помощью графа инструментов.

---

## Структура туториалов

### Начальный уровень (Beginner)

Для тех, кто только начинает работу с GraphArchitect.

- **01_quick_start.md** - Быстрый старт за 5 минут
- **02_basic_concepts.md** - Основные концепции системы
- **03_first_workflow.md** - Первый workflow шаг за шагом
- **04_understanding_tools.md** - Понимание инструментов и агентов

### Средний уровень (Intermediate)

Для понимания внутренних механизмов.

- **01_graph_algorithms.md** - Алгоритмы поиска путей (Dijkstra, A*, Yen, ACO)
- **02_tool_selection.md** - Softmax выбор инструментов

### Уровень развертывания (Deployment)

Для создания инфраструктуры.

- **01_embedding_systems.md** - Системы эмбеддингов (Simple, Infinity, Faiss)
- **02_production_deployment.md** - Production развертывание

### Типовые Workflow задачи (Workflows)

Готовые сценарии для распространенных задач.

- **customer_support.md** - Обработка запросов поддержки
- **content_creation.md** - Создание контента
- **data_analysis.md** - Анализ данных
- **code_review.md** - Ревью кода
- **research_workflow.md** - Исследовательские задачи
- **document_processing.md** - Обработка документов

## Как использовать туториалы

### Последовательное изучение

1. **Неделя 1**: Beginner уровень (5 туториалов)
   - Понимание базовых концепций
   - Запуск первых workflow
   - Работа с API

2. **Неделя 2**: Intermediate уровень (5 туториалов)
   - Глубокое понимание алгоритмов
   - Создание собственных инструментов
   - Настройка системы обучения

3. **Неделя 3**: Advanced уровень + Workflows
   - Production настройка
   - Оптимизация производительности
   - Готовые сценарии

### Выборочное изучение

Если нужно решить конкретную задачу:
- Выберите соответствующий workflow
- Следуйте пошаговой инструкции
- Адаптируйте под свои нужды

## Формат туториалов

Каждый туториал содержит:

1. **Описание** - что вы узнаете
2. **Требования** - что нужно знать заранее
3. **Теория** - концепции и объяснения
4. **Практика** - код и примеры
5. **Упражнения** - задания для закрепления
6. **Итоги** - ключевые выводы

## Уровни сложности

### Beginner (Начинающий)

- Требуется: Базовые знания Python
- Время: 1-2 часа
- Результат: Умение запускать готовые workflow

### Intermediate (Средний)

- Требуется: Понимание ООП, знание Python
- Время: 3-5 часов
- Результат: Создание собственных инструментов и workflow

### Advanced (Продвинутый)

- Требуется: Опыт с ML, понимание алгоритмов
- Время: 5-10 часов
- Результат: Production развертывание, оптимизация
