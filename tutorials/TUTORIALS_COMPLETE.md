## Покрытие тем

### Базовые концепции

- Граф инструментов
- Коннекторы и форматы данных
- Стратегии выполнения
- Workflow и шаги
- API endpoints

### Алгоритмы

- Dijkstra (кратчайший путь)
- A* (с эвристикой)
- Yen (топ-K путей)
- Ant Colony (вероятностный)
- Softmax с температурой
- Policy Gradient

### Компоненты

- NLI (Natural Language Interface)
- InstrumentSelector (выбор инструментов)
- ExecutionOrchestrator (оркестрация)
- TrainingOrchestrator (обучение)
- GraphStrategyFinder (поиск стратегий)

### Системы

- Эмбеддинги (Simple, Infinity)
- k-NN (Naive, Faiss)
- База данных (SQLite)
- Web API (FastAPI)
- Обучение (Policy Gradient)

### Production

- Deployment (Docker)
- Мониторинг
- Оптимизация
- Масштабирование
- Безопасность
