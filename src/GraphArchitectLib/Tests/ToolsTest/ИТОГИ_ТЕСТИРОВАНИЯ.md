### ⚠️ ВАЖНАЯ: Некорректная формула расчета стоимости

**Проблема:** В `BaseTool.py` (строка 34):
```python
cost = prob_true / (cost_api + 1)
```

**Почему это проблема:**

Для алгоритма Дейкстры меньший вес = более короткий путь.

Текущая формула:
- API стоимость = 10 → cost = 1/11 = 0.09 (**меньше** → **предпочтительнее**)
- API стоимость = 1 → cost = 1/2 = 0.5 (**больше** → **менее предпочтительно**)

🔴 **Это обратная логика!** Дорогие API становятся предпочтительными!

**Правильная формула должна быть:**
```python
cost = (cost_api + 1) / prob_true
```

Тогда:
- API стоимость = 10 → cost = 11/1 = 11 (**больше** → **менее предпочтительно**) ✅
- API стоимость = 1 → cost = 2/1 = 2 (**меньше** → **предпочтительнее**) ✅

**Статус:** ⚠️ НЕ ИСПРАВЛЕНО (требует изменения базового класса)

**Влияние:**
- Алгоритм выбирает НЕ оптимальные пути
- В ДЕМО 3 выбран путь стоимостью 10 вместо 7
- В ДЕМО 7 выбран путь стоимостью 15 вместо 5
