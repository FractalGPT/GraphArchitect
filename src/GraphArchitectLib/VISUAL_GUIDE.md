## 🧮 Формулы (визуально)

### LogLoss (вес ребра графа)

```
    reputation
         │
         ▼
    max(rep, 1e-6)  ← защита от log(0)
         │
         ▼
      -log(rep)
         │
         ▼
       weight

Примеры:
  rep=0.99 → weight=0.010  (отличный инструмент, малый вес)
  rep=0.50 → weight=0.693  (средний инструмент)
  rep=0.10 → weight=2.303  (плохой инструмент, большой вес)
```

### Softmax с температурой

```
    logits          temperature
      │                  │
      ├──────────────────┤
      ▼                  ▼
   logit / T
      │
      ▼
    exp()
      │
      ▼
  нормализация (/ Σ)
      │
      ▼
  probabilities

Низкая T (0.1):        Высокая T (10.0):
  P1 = 0.95              P1 = 0.28
  P2 = 0.04              P2 = 0.24
  P3 = 0.01              P3 = 0.24
  └─ концентрация!       P4 = 0.24
                         └─ равномерно!
```

### Policy Gradient

```
   execution
       │
       ▼
  quality_score (reward)
       │
       ├─────────────────┐
       │                 │
       ▼                 ▼
   old_reputation    reward
   (baseline)           │
       │                │
       └────► (-)  ◄────┘
              │
              ▼
          advantage
              │
              ▼
       lr * advantage
              │
              ▼
    old_rep + Δrep
              │
              ▼
    clip(rep, 0.01, 0.99)
              │
              ▼
        new_reputation
```
