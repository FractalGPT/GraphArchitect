# ⚡ SQLite - Быстрый старт (2 минуты)

## 🎯 Что это?

**SQLite3 интеграция** - персистентное хранилище для GraphArchitect Web API.

**Преимущества:**
- ✅ Встроен в Python (нет установки)
- ✅ Данные сохраняются между перезапусками
- ✅ Агенты из БД (не хардкод)
- ✅ История обучения накапливается

---

## 🚀 3 команды для старта

### 1. Инициализация БД (10 секунд)

```bash
cd Web
python db_manager.py init
```

**Создается:** `grapharchitect.db` (файл БД)

### 2. Загрузка агентов (5 секунд)

```bash
python db_manager.py load_agents
```

**Загружается:** 24 агента из `agent_library.py` → БД

### 3. Запуск сервера (готово!)

```bash
python main.py
```

**Логи должны показать:**
```
✅ SQLiteRepository инициализирован (grapharchitect.db)
✅ Используется SQLite репозиторий
📦 Загружено агентов из БД: 24
```
